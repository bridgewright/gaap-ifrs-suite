# Sample Outputs

The samples allow a reviewer to inspect the product without installing it.

## Conversion sample

`track1-converter/` contains a synthetic K-GAAP trial balance, supporting inputs, converted statements, reconciliation, impact analysis, difference analysis, and machine-readable output.

Begin with `difference_analysis.md` to inspect how the engine separates mapping, adjustment rationale, citation status, and quantified balance-sheet and profit effects.

## Retrieval sample

`track2-chatbot/lease-recognition-QA.md` demonstrates the intended answer structure for a lease-recognition question: source text and provenance first, followed by separately labeled interpretation and comparison.

The source paragraph shown in a sample remains third-party accounting-standard material and is not licensed under this repository's MIT License. The full source corpus is not distributed.

See the repository README for installation, data-rights boundaries, and current limitations.
